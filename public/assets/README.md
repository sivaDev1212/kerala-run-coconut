# Custom 3D models

Drop GLB files here using EXACTLY these names (any missing file falls back to a procedural model):

character.glb, coconut.glb, milk-bottle.glb, wooden-crate.glb, coconut-tree.glb, kerala-house.glb, wooden-boat.glb

Tune scale / rotation / offset per model in `src/config/assets.js`. See the main README for details.
